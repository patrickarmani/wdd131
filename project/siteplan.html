Doctor Nature - Website Planning Document

1. Site Name:

Doctor Nature - Plants that heal

This name represents a catalog of medicinal plants that can promote health and well-being.

2. Site Purpose:

This website provides information about medicinal plants, their recommended uses, and their scientific names.

3. Scenarios:

Which plant is good for relieving insect bites?

In which countries can this plant be found?
